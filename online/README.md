# 迷途神廟線上私人房

## 啟動

```powershell
cd online
npm install
npm start
```

兩位玩家用瀏覽器開啟 `http://localhost:3000`。若不在同一台電腦，請把伺服器部署到可公開連線、支援 WebSocket 的 Node.js 環境。

## 讓不同電腦點網址就玩

專案根目錄已附 `render.yaml`。部署後，玩家不必安裝 Node.js，也不必跟主辦者在同一個網路，只要開啟 Render 提供的 HTTPS 網址即可。

1. 將整個「神廟練習器」資料夾推送到 GitHub 或 GitLab 儲存庫。
2. 登入 Render，選擇 **New → Blueprint**。
3. 連接該儲存庫；Blueprint 路徑使用根目錄的 `render.yaml`。
4. 確認並部署 `lost-temple-private-room`。
5. 完成後分享 Render 產生的 `https://……onrender.com` 網址。

免費執行個體閒置後可能休眠，所以第一位玩家隔一段時間重新開啟時，需要等待伺服器喚醒。房間資料目前只存在伺服器記憶體內；重新部署或伺服器重啟後，舊房號會失效，重新建立即可。

## 房主權限

主辦者可在大廳調整：

- 真實機率／均勻隨機抽圖
- 隨機佈局／指定佈局編號
- 搶 1、3、5 或 7 勝
- 是否共享撞門情報
- 回合結束是否顯示答案

設定更新和開局命令都會在伺服器再次檢查房主身分，訪客不能只靠修改瀏覽器畫面越權。

目前定位是私人房原型：伺服器判定誰先抵達終點，但玩家移動仍由各自瀏覽器模擬。若要做公開排名或比賽，下一步應把碰撞與位置計算搬到伺服器端。
