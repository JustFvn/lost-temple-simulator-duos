# 迷途神廟｜TEMPLE DUEL

獨立的雙人線上遊戲：首頁 → 私人房大廳 → 即時對戰 → 回合／整場結算。沒有把單人模擬器藏在彈出視窗後面；原本根目錄的單人版與 `versus/` 不受影響。

## 啟動

```powershell
cd online
npm.cmd install
npm.cmd start
```

兩位玩家用瀏覽器開啟 `http://localhost:3000`。若不在同一台電腦，請把伺服器部署到可公開連線、支援 WebSocket 的 Node.js 環境。

## 讓不同電腦點網址就玩

專案根目錄已附 `render.yaml`。部署後，玩家不必安裝 Node.js，也不必跟主辦者在同一個網路，只要開啟 Render 提供的 HTTPS 網址即可。

主辦者可複製含房號的邀請連結；受邀玩家開啟後先輸入自己的名稱，再按「加入房間」。房主開始回合時，兩端會同步顯示 3、2、1 倒數，倒數結束前不能移動或取得勝利。

1. 推送專案根目錄的 `render.yaml` 與完整 `online/`（不用 `node_modules/`、`.env` 或測試截圖）。
2. 登入 Render，選擇 **New → Blueprint**。
3. 連接該儲存庫；Blueprint 路徑使用根目錄的 `render.yaml`。
4. 確認並部署 `lost-temple-private-room`。
5. 完成後分享 Render 產生的 `https://……onrender.com` 網址。

免費執行個體閒置後可能休眠，所以第一位玩家隔一段時間重新開啟時，需要等待伺服器喚醒。房間資料目前只存在伺服器記憶體內；重新部署或伺服器重啟後，舊房號會失效，重新建立即可。

## 房主權限

主辦者可在大廳調整：

- 官方佈局／程式生成迷宮
- 官方模式：真實機率／均勻隨機、隨機佈局／指定佈局編號 0–124
- 自訂勝利分數：1–99 的整數；1、3、5、7 是快捷按鈕，不是限制
- 是否共享撞門情報
- 回合結束是否顯示答案

設定更新和開局命令都會在伺服器再次檢查房主身分，訪客不能只靠修改瀏覽器畫面越權。

修改規則會重置比分，回合中設定鎖定。先到 E3 拿一分；達到目標分數才算贏得整場，房主可選「再來一場」。對手離開會取消回合、重置比分；房主離開則關閉房間。

## 生成迷宮模式

`maze.js` 自行生成門的開閉，**不抽選、不拼接 125 張官方路線**。沿用 5×5 房間、A3 起點、E3 終點與 A3–B3 實牆：

- 生成兩條中間互不交叉的路，從起點左右分岔，到終點匯合。
- 添加少量死路，保留探門玩法；不增加第三條通關路線。
- 伺服器每回合生成一次，將同一張迷宮送給兩位玩家。
- 生成後再驗證通關路線數恰為兩條；極端亂數下有保底可通關地圖。

「全新」代表每回合重新生成，沒有保存歷史去排除重複地圖。回合後揭曉兩條路線可由房主關閉。

操作：WASD 或方向鍵只控制自己的角色；手機提供方向按鈕。同步倒數結束前不能移動或計分，計時由伺服器共同起跑時間計算。

## 本機測試

```powershell
cd online
npm.cmd install
npm.cmd run check
# 另一個 PowerShell 先啟動 npm.cmd start，再執行：
npm.cmd run test:integration
```

`check` 檢查模組語法、頁面 ID、125 張官方地圖及 1,000 張生成地圖，包含兩條分岔及角色碰撞半徑的通行測試。`test:integration` 驗證兩個 Socket.IO 客戶端的權限、倒數、自訂分數、整場勝利與離房。

桌機／手機瀏覽器自動測試（使用隔離的無頭瀏覽器）：

```powershell
$env:CHROME_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm.cmd run test:gui
```

沒有 Chrome 可用 `npx.cmd playwright install chromium`，省略 `CHROME_PATH` 即可。伺服器需先啟動；自訂網址可設 `$env:TEST_URL = 'http://localhost:3010'`。測試截圖放在已忽略的 `test-artifacts/`，測試會用真實鍵盤走完整條生成路線、確認整場結算與手機版沒有水平溢出。

目前定位是私人房原型：伺服器判定誰先抵達終點，但玩家移動仍由各自瀏覽器模擬。若要做公開排名或比賽，下一步應把碰撞與位置計算搬到伺服器端。
